# FoodLens

FoodLens lets you snap or upload food photos and instantly get AI-generated insights, nutrition breakdowns, and calorie estimates. It also includes a built-in nutrition assistant chatbot, a save feature and articles regarding food and nutrtion.

## Achievements

**1st Place** — TECHCORPShack 2025

## Tech Stack

- **iOS App** - Swift
- **Backend** - FastAPI
- **AI** - OpenAI API
